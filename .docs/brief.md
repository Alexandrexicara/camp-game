# Animal Camp

- One-line positioning: Plataforma 2D pixel art retrô onde um animalzinho explora fases de acampamento na floresta
- Target users: Jogadores casuais de todas as idades
- Core features:
  1. Personagem animal (guaxinim) com corrida, pulo e coleta de itens
  2. Fases de plataforma com terreno de floresta/acampamento (árvores, fogueiras, tendas)
  3. Coleta de estrelas/acorns para pontuar, com inimigos simples (sapos/cogumelos)
- Important features (P1):
  1. Tela de início temática (Animal Camp) e tela de Game Over
  2. HUD pixel art com score e vidas
- Device strategy: adaptive
- Design style: Pixel art retrô 8-bit, paleta de cores vibrante e fofa, temática floresta/acampamento
- Technical constraints: Phaser 3 + Next.js template
- Nova Agent: not needed

- Current iteration: Construção inicial completa (Phases 1-6)
